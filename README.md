# Movie Manager System

A simple Python application built using Object-Oriented Programming (OOP) to manage a digital movie catalog. It allows users to add, remove, search, and display movies with details like director, release year, and ratings.

## Features
* **Add Movies:** Catalog new movies with specialized data.
* **Remove Movies:** Delete films securely from the tracking list.
* **Search System:** Search through titles ignoring case sensitivity.
* **Formatted Output:** Beautiful terminal printing using python's representation (`__repr__`) method.
